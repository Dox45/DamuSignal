# Organiser starter kit (not written by the team)

Everything in this folder was provided by the hackathon organisers (Talo Africa for Terumo BCT) in the
Applicant's Kit and is kept here unmodified for reference only:

- `gen.py`: the organisers' synthetic dataset generator. Run `python starter_kit/gen.py` to rebuild the CSVs into `starter_kit/out/`, then copy them to the repository root.
- `index.html`, `logos.png`: the organisers' dataset landing page.
- `DATA_DICTIONARY.md`: the organisers' column definitions.

None of these files are part of the team's submission code. The team's code lives in `gitcodes/`, `ui/` and `frontend/`.
